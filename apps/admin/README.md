# Administration

Fondation Next.js du back-office KORA+. Le shell s’appuie sur les composants
officiels `DashboardLayout` et `AppContent` de `@adminlte/react`. Les treize
zones de navigation sont présentes sous forme de repères honnêtes, sans donnée,
route métier, authentification, autorisation ou action opérationnelle.

Le thème est exclusivement clair. L’indexation est désactivée par les
métadonnées et par `robots.txt`.

## Commandes

Depuis ce dossier :

```powershell
npm.cmd run dev
npm.cmd run format
npm.cmd run lint
npm.cmd run typecheck
npm.cmd run test
npm.cmd run build
```
