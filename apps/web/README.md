# Web public

Fondation Next.js du site public KORA+. Ce lot fournit uniquement le shell
accessible, les métadonnées SEO de base et les états techniques. Il n’appelle
aucune API et ne contient ni achat, ni lecture média, ni téléchargement.

## Commandes

Depuis ce dossier :

```powershell
npm.cmd run dev
npm.cmd run format
npm.cmd run lint
npm.cmd run typecheck
npm.cmd run test
npm.cmd run build
```
