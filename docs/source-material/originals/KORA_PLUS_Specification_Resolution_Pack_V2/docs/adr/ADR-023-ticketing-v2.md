# ADR-023 - Ticketing scope

Status: Accepted - Deferred V2  
Date: 2026-07-25

## Decision

Remove complete ticketing from the MVP: no Event/Ticket/QR model, seed, screen, API or acceptance criterion. Preserve concert discovery and live/replay content only. V2 ticketing will be a dedicated slice with inventory, oversell prevention, QR signing, validation, refund and venue operations.

## Consequences

The MVP focuses on reliable digital content commerce and avoids a second high-risk transaction domain.
