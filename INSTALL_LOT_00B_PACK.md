# Installation du pack Lot 00B

Ce pack doit être extrait **dans** le dossier Windows :

`C:\Users\moham\Music\KORA-PLUS-FINAL`

Après extraction, le dossier doit notamment contenir :

```text
KORA-PLUS-FINAL/
  docs/
    governance/
      AI_OPERATING_MODEL.md
      CLEAN_ROOM_SCOPE.md
    roadmap/
      MASTER_EXECUTION_BLUEPRINT.md
    prompts/
      CODEX_LOT_00_READ_ONLY_PREFLIGHT.md
      CODEX_LOT_00B_READINESS_REMEDIATION.md
      SPRINT_0_CLEAN_ROOM_BOOTSTRAP.md
    source-material/
      references/
        adminlte/
          AdminLTE-master.zip
          README.md
```

Ne pas extraire `AdminLTE-master.zip`.

Ne pas lancer encore `SPRINT_0_CLEAN_ROOM_BOOTSTRAP.md`.

La seule instruction Codex à exécuter après installation est :

```text
Lis intégralement
docs/prompts/CODEX_LOT_00B_READINESS_REMEDIATION.md
et exécute exactement ce Lot 00B.

Arrête-toi après le verdict READY FOR SPRINT 0.1 ou
NOT READY FOR SPRINT 0.1. Ne commence pas Sprint 0.1.
```
